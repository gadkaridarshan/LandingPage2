Features

Everything you need to ship a great landing page

A thoughtful design system, responsive layout, and production-ready components — all in a single static site.

  • Pixel-perfect design

    Carefully tuned typography, spacing, and color tokens create a cohesive visual identity out of the box.

  • Responsive by default

    The grid and components adapt gracefully from mobile to ultra-wide displays with no extra work.

  • Ship in minutes

    Pure static assets, zero build steps, and no environment configuration. Deploy to any static host.

  • Accessible & inclusive

    Semantic landmarks, visible focus states, reduced-motion support, and proper ARIA labels throughout.

  • Modern type system

    Inter for body copy and Sora for display headings deliver a refined editorial feel at every breakpoint.

  • Built-in contact form

    Client-side validation with accessible error messaging — wired up and ready for your backend.
