# LandingPage2

A polished, accessible landing page scaffold built with semantic HTML and modern CSS.

## Structure

- `public/index.html` — page markup (hero, features, contact)
- `public/styles/base.css` — design tokens, layout, typography, hero, footer
- `public/styles/features.css` — features section grid styles
- `public/scripts/main.js` — small vanilla JS enhancements

## Features section

A responsive grid of feature cards (icon + title + short description):

- 1 column on mobile (< 560px)
- 2 columns on small tablets (≥ 560px)
- 3 columns on desktop (≥ 880px)

Cards align to a consistent track at every breakpoint.
