Features

Everything you need to launch — nothing you don't.

A focused toolkit for shipping beautiful, fast, accessible landing pages without the usual front-end yak-shaving.

  • Ship in minutes

    Drop the files onto any static host or CDN. No build pipeline, no dependencies, no environment variables to babysit.

  • Pixel-perfect design

    A thoughtful type scale, consistent spacing tokens, and modern gradients that look polished out of the box.

  • Accessible by default

    Semantic HTML, focus styles, and ARIA labels are baked in so your page works for every visitor, on every device.

  • Responsive everywhere

    A fluid grid, fluid type, and mobile-first breakpoints mean your layout looks great from phone to ultrawide.

  • Production-ready

    Inline validation, smooth-scroll nav, and dynamic footer year are wired up — so you don't have to write a single line of glue code.

  • Easy to customize

    CSS custom properties power the whole design system — swap a few tokens and the whole site rebrands in seconds.
